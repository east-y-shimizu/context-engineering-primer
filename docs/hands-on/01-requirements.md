# 要件定義

## アプリケーション概要

書籍のバーコード画像から ISBN を読み取り、書籍情報を表示するウェブアプリケーション。

## 機能要件

### FR-01: 画像アップロード機能
- **説明**: ユーザーがバーコードを含む画像をアップロードできる
- **受け入れ基準**:
  - ファイル選択ボタンが表示されている
  - 画像ファイル（JPEG、PNG）を選択できる
  - 選択した画像のプレビューが表示される

### FR-02: バーコード読み取り機能
- **説明**: アップロードされた画像からISBNバーコードを自動で読み取る
- **受け入れ基準**:
  - 画像から ISBN-13（EAN-13）形式のバーコードを検出できる
  - 読み取り中は処理中であることを表示する
  - バーコードが検出されない場合はエラーメッセージを表示する

### FR-03: 書籍情報取得機能
- **説明**: 読み取ったISBNをもとにOpenBD APIから書籍情報を取得する
- **受け入れ基準**:
  - OpenBD API（`https://api.openbd.jp/v1/get?isbn={ISBN}`）にリクエストを送信する
  - レスポンスから書籍情報をパースする
  - API呼び出し中はローディング状態を表示する
  - 書籍情報が見つからない場合はエラーメッセージを表示する

### FR-04: 書籍情報表示機能
- **説明**: 取得した書籍情報を読みやすく表示する
- **受け入れ基準**:
  - 以下の情報を表示する：
    - ISBN
    - タイトル
    - 著者
    - 出版社
    - 発行日
    - 表紙画像（利用可能な場合）
  - 情報が取得できない項目は「不明」と表示する

## 非機能要件

### NFR-01: レスポンシブ対応
- **説明**: モバイルデバイスでも快適に利用できる
- **受け入れ基準**:
  - 画面幅600px以下でもレイアウトが崩れない
  - タッチ操作に対応している
  - フォントサイズが読みやすい

### NFR-02: エラーハンドリング
- **説明**: 想定されるエラーに対して適切なメッセージを表示する
- **受け入れ基準**:
  - バーコード検出失敗時のエラーメッセージ
  - API通信エラー時のエラーメッセージ
  - 書籍情報が見つからない場合のメッセージ
  - エラーメッセージが視覚的に目立つ

### NFR-03: パフォーマンス
- **説明**: ユーザーがストレスを感じない応答速度
- **受け入れ基準**:
  - 画像読み取りは5秒以内に完了する
  - API呼び出しは3秒以内に完了する
  - ローディング中はインジケーターを表示する

## API仕様

### OpenBD API

**エンドポイント**: `https://api.openbd.jp/v1/get`

**リクエスト**:
```
GET https://api.openbd.jp/v1/get?isbn={ISBN}
```

**レスポンス例**:
```json
[
  {
    "summary": {
      "isbn": "9784XXXXXXXXX",
      "title": "書籍タイトル",
      "author": "著者名",
      "publisher": "出版社名",
      "pubdate": "YYYYMMDD",
      "cover": "https://example.com/cover.jpg"
    },
    "onix": {
      // 詳細情報
    }
  }
]
```

**注意事項**:
- ISBNが見つからない場合は `[null]` が返る
- 無料で利用可能、APIキー不要
- 日本の書籍に特化

## 制約事項

1. バーコードはISBN-13（EAN-13）形式のみ対応
2. 画像ファイルのサイズ制限はブラウザのデフォルトに従う
3. OpenBD APIのレート制限に準拠する
4. オフライン利用は非対応
